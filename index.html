About me

I’m a second-year college student focused on software development, building toward a career in AI engineering.

My path started with HTML, CSS and JavaScript, then widened into React, Node.js with Express, and PostgreSQL. Each layer taught me to think a little more clearly about how a product holds together, from the database to the interface.

I’m curious by default and deterministic by habit. I like small problems that have a definite answer, and I don’t move on from a concept until I can explain why it works. That habit is slow at the start and much faster later.

Right now I’m integrating LLM APIs into side projects, learning the mechanics of retrieval-augmented generation, and shipping what I learn on GitHub. The goal is simple: understand the whole path, then make it useful.

My projects

SDO Student Discipline Office

A Progressive Web App for NU Fairview that tracks disciplinary cases, sanctions, appointments and clearance in one place.

  • React 19
  • TypeScript
  • PWA
  • Prisma
  • Neon
Details

Students follow their cases, sanctions and appointments, submit requirements and search the digital handbook, while administrators record violations and manage case statuses through role-based access. It installs as a PWA and runs on React 19, TypeScript and a Postgres database.

Source Live demo

Lumen RAG gateway

A multi-tenant RAG gateway that answers only from a business’s own documents, quotes its sources and routes each question to the right model.

  • TypeScript
  • Express
  • PostgreSQL
  • pgvector
  • RAG
Details

A business signs in, uploads documents and receives an API key that its own chatbot can call. Every project is an isolated tenant: Lumen answers only from that tenant’s documents, quotes the passages it used, picks a cheap or an expensive model per question, and reports the estimated provider cost in the dashboard.

Source Live demo

PromptFlow LLM canvas

A visual, node-based playground for chaining prompts, branching them and watching every step stream in with its cost.

  • React
  • TypeScript
  • Vite
  • Six LLM providers
Details

Wire Input, Prompt, Agent, Merge and Output nodes on a canvas, then run the flow and watch results stream in with tokens, cost and time per step. Keys stay in the browser and requests go straight to the provider, with saved flows, undo/redo, a command palette and Markdown reports for every run.

Source Live demo

Instralize algorithm studio

An interactive algorithm studio for stepping through sorting, searching and recursion, or writing your own sort in Code Lab.

  • React
  • TypeScript
  • Vite
  • Web Workers
Details

Explore eight sorting algorithms, linear and binary search, and recursion with play, pause, step and timeline controls. Code Lab runs your own sort through an AST interpreter inside a Web Worker, and linked visualization and execution-map nodes show the same run side by side on an infinite canvas.

Source Live demo
